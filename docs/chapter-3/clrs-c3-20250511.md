# 第3章 実行時間の特徴づけ

## 3.1 漸近記法とは何か

前章では、挿入ソートの実行時間を $T(n) = an^2 + bn + c$ のように具体的に書き下し、$n$ が大きくなると最高次の項 $n^2$ が支配的になることを見た。そして定数係数や低次項を捨てて $\Theta(n^2)$ と表した。

このように、**入力サイズ $n$ が十分大きくなったときの実行時間の増え方（増加のオーダー）だけに注目する** 考え方を **漸近的**（asymptotic）な解析と呼ぶ。本章では、$\Theta$・$O$・$\Omega$ をはじめとする **漸近記法**（asymptotic notation）を正確に定義し、使い分けられるようにする。

**なぜ定数や低次項を捨てるのか**

- 実行時間の絶対値は計算機の速度に依存し、アルゴリズム本来の良し悪しを測れない（第1章で述べたとおり）。
- $n$ が大きくなると、最高次の項以外の寄与は相対的に無視できるほど小さくなる。
- 定数係数や低次項に細かくこだわるより、「$n^2$ なのか $n\log n$ なのか」という **オーダーの違い** の方が、入力が大きいときの性能を圧倒的に左右する。

漸近記法は、これらの「本質的でない違い」を意図的に捨て、アルゴリズムの **スケーラビリティ** を比較するための共通言語である。

## 3.2 O・Ω・Θ記法

3つの記法は、ある関数 $f(n)$ を別の単純な関数 $g(n)$ で「どちら側から押さえるか」で区別される。

- $O$ … **上界**（高々これくらい）
- $\Omega$ … **下界**（少なくともこれくらい）
- $\Theta$ … **上下両方**（ちょうどこのオーダー）

直感的なイメージは次のとおり。

```
        c2·g(n) ─────────  ← O が押さえる「天井」
                 ╱
        f(n) ───╱           Θ は天井と床の両方で挟む
               ╱
        c1·g(n) ─────────  ← Ω が押さえる「床」

        n0 より右では、この挟み込みが常に成り立つ
```

### 3.2.1 O記法（漸近的上界）

$O(g(n))$ は「$g(n)$ の定数倍を **天井** として、$f(n)$ がそれを超えない」関数の集合。

$$
O(g(n)) = \bigl\{\, f(n) \mid \exists\, c, n_0 > 0 \text{ s.t. } \forall n \ge n_0,\ 0 \le f(n) \le c\,g(n) \,\bigr\}
$$

「最悪でもこのオーダー以下」と言いたいときに使う。たとえば挿入ソートの実行時間は、どんな入力でも $O(n^2)$ で抑えられる。なお $O$ は上界なので、$2n+3 = O(n^2)$ のように **ゆるい上界** を述べても（不正確ではあるが）間違いではない。

### 3.2.2 Ω記法（漸近的下界）

$\Omega(g(n))$ は「$g(n)$ の定数倍を **床** として、$f(n)$ がそれを下回らない」関数の集合。

$$
\Omega(g(n)) = \bigl\{\, f(n) \mid \exists\, c, n_0 > 0 \text{ s.t. } \forall n \ge n_0,\ 0 \le c\,g(n) \le f(n) \,\bigr\}
$$

「少なくともこのオーダーはかかる」と下から保証したいときに使う。たとえば「比較に基づくソートはどう頑張っても $\Omega(n\log n)$ かかる」という主張は、問題そのものの難しさ（下界）を述べている。

### 3.2.3 Θ記法（漸近的に厳密な限界）

$\Theta(g(n))$ は、$g(n)$ の定数倍で **上からも下からも挟める** 関数の集合。

$$
\Theta(g(n)) = \bigl\{\, f(n) \mid \exists\, c_1, c_2, n_0 > 0 \text{ s.t. } \forall n \ge n_0,\ 0 \le c_1\,g(n) \le f(n) \le c_2\,g(n) \,\bigr\}
$$

実行時間が具体的に求まっていて「ちょうどこのオーダー」と言い切れるときに使う、最も情報量の多い記法である。

### 3.2.4 三者の関係

$O$ と $\Omega$ がそろえば $\Theta$ になる。これは定義から直ちに導ける重要な定理である。

$$
f(n) = \Theta(g(n)) \quad\Longleftrightarrow\quad f(n) = O(g(n)) \ \text{かつ}\ f(n) = \Omega(g(n))
$$

実際に $\Theta$ を示すとき、上界と下界を別々に証明してから合わせる、という手順をよく使う。

#### 演習 3.1: 定義から示す

$\dfrac{1}{2}n^2 - 3n = \Theta(n^2)$ を、$\Theta$ の定義を満たす定数 $c_1, c_2, n_0$ を具体的に1組見つけることで示せ。

ヒント：$c_1 n^2 \le \frac{1}{2}n^2 - 3n \le c_2 n^2$ の両辺を $n^2$ で割り、$n$ が大きいときに成り立つ $c_1, c_2$ を探す。

## 3.3 形式的な定義と使い方

### 3.3.1 「記法は集合」という見方

$O(g(n))$ などは本来 **関数の集合** である。本来は $f(n) \in O(g(n))$ と書くべきだが、慣習として $f(n) = O(g(n))$ という等号の書き方をする。この「$=$」は左右が等しいという意味ではなく、「$f(n)$ は $O(g(n))$ という集合に属する」という **片方向** の意味で読む。

そのため、式の途中に漸近記法を混ぜることもできる。

$$
2n^2 + 3n + 1 = 2n^2 + \Theta(n)
$$

これは「$3n+1$ を、ある $\Theta(n)$ の関数で置き換えてよい」という意味であり、左から右へは読めても、右から左へは読めない（向きのある等号）。

### 3.3.2 o記法と ω記法（厳密でない限界）

$O$ と $\Omega$ は「$\le$ / $\ge$」に相当する（同じオーダーを含んでよい）。これに対し、**厳密に小さい / 大きい**（「$<$ / $>$」に相当）を表すのが小文字の $o$ と $\omega$ である。

$$
o(g(n)) = \bigl\{\, f(n) \mid {}^{\forall}c > 0,\ \exists\, n_0 > 0 \text{ s.t. } \forall n \ge n_0,\ 0 \le f(n) < c\,g(n) \,\bigr\}
$$

$O$ では「ある1つの $c$ について」だったのが、$o$ では「**どんな $c$ をとっても**」に変わっている点に注意。これは $f$ が $g$ より **真に遅く** 増加することを意味する。極限で書くと分かりやすい。

$$
f(n) = o(g(n)) \iff \lim_{n\to\infty} \frac{f(n)}{g(n)} = 0,
\qquad
f(n) = \omega(g(n)) \iff \lim_{n\to\infty} \frac{f(n)}{g(n)} = \infty
$$

たとえば $2n = o(n^2)$ だが $2n^2 \ne o(n^2)$、また $n^2 = \omega(n)$ である。

### 3.3.3 漸近記法が持つ性質

実数の大小比較とのアナロジーで覚えると整理しやすい。

| 性質 | 漸近記法での例 | 実数とのアナロジー |
|:---|:---|:---|
| 推移律 | $f=O(g)$ かつ $g=O(h)$ ⇒ $f=O(h)$ | $a \le b \le c \Rightarrow a \le c$ |
| 反射律 | $f = O(f)$ | $a \le a$ |
| 対称律 | $f = \Theta(g) \iff g = \Theta(f)$ | $a = b \iff b = a$ |
| 転置対称律 | $f = O(g) \iff g = \Omega(f)$ | $a \le b \iff b \ge a$ |

推移律はすべての記法（$O, \Omega, \Theta, o, \omega$）で成り立つ。一方、実数の三分律（任意の2数は大小が必ず決まる）に対応する性質は **成り立たない**。$f(n) = n^{1+\sin n}$ と $g(n) = n$ のように、$O$ でも $\Omega$ でもない（比較不能な）関数の組が存在するためである。

#### 演習 3.2: 記法の対応づけ

次の各関数を、増加が遅い順に $\Theta$ クラスで並べよ。同じクラスのものはまとめてよい。

$$
n^2,\quad 2^{\,n},\quad n\log n,\quad \log n,\quad n,\quad 1,\quad n!,\quad n^3
$$

## 3.4 標準的な関数と増加の比較

漸近記法を使いこなすには、よく現れる関数どうしの増加の速さを把握しておく必要がある。

### 3.4.1 単調性・床関数と天井関数

- **単調増加**：$m \le n \Rightarrow f(m) \le f(n)$。**狭義単調増加** は $m < n \Rightarrow f(m) < f(n)$。
- **床関数** $\lfloor x \rfloor$（$x$ 以下の最大の整数）と **天井関数** $\lceil x \rceil$（$x$ 以上の最小の整数）は、分割統治で「半分に割る」ときに頻出する。次の不等式が基本。

$$
x - 1 < \lfloor x \rfloor \le x \le \lceil x \rceil < x + 1,
\qquad
\Bigl\lceil \frac{n}{2} \Bigr\rceil + \Bigl\lfloor \frac{n}{2} \Bigr\rfloor = n
$$

漸近的には $\lfloor n/2 \rfloor = \Theta(n)$ のように、床・天井は無視してオーダーを論じてよい。

### 3.4.2 多項式・指数・対数・階乗

増加の速さは、おおまかに次の不等式の連鎖で覚える（$a > 1$、$b > 0$、$n \to \infty$）。

$$
\underbrace{1 \prec \log n \prec n^{b}}_{\text{対数 } \prec \text{ 多項式}}
\ \prec\
\underbrace{a^{\,n} \prec n!}_{\text{指数 } \prec \text{ 階乗}}
\ \prec\ n^{\,n}
$$

それぞれの根拠となる主要な事実を挙げる。

**多項式**：次数 $d$ の多項式 $p(n) = \sum_{i=0}^{d} a_i n^i$（$a_d > 0$）は $p(n) = \Theta(n^d)$。最高次の項だけがオーダーを決める。

**指数は任意の多項式に勝つ**：

$$
n^{b} = o(a^{\,n}) \quad (a > 1,\ b > 0)
$$

どんなに次数の高い多項式でも、底が1より大きい指数関数にはいつか必ず追い抜かれる。$n^{100} = o(1.001^{\,n})$ さえ成り立つ。これが「指数時間アルゴリズムは現実的でない」ことの数学的な裏づけである。

**対数は任意の正のべきに負ける**：

$$
\log^{b} n = o(n^{a}) \quad (a > 0,\ b > 0)
$$

対数はきわめてゆっくり増える。底の違いは定数倍にすぎない（$\log_a n = \log_b n / \log_b a$）ので、漸近記法の中では底を省略して単に $\log n$ と書くことが多い。

**階乗とスターリングの近似**：階乗は指数よりさらに速く増える。

$$
n! = \sqrt{2\pi n}\,\Bigl(\frac{n}{e}\Bigr)^{n}\Bigl(1 + \Theta\bigl(\tfrac{1}{n}\bigr)\Bigr)
$$

ここから次が導ける。第1章の TSP の試算（$(10^6)!$ が約557万桁）も、この近似で計算した。

$$
n! = o(n^{\,n}),\qquad n! = \omega(2^{\,n}),\qquad \lg(n!) = \Theta(n \lg n)
$$

最後の $\lg(n!) = \Theta(n\lg n)$ は、比較ソートの下界 $\Omega(n\log n)$ を導くときに使う重要な等式である。

#### 演習 3.3: 増加の比較

次の各組について、$f(n) = O(g(n))$、$f(n) = \Omega(g(n))$、$f(n) = \Theta(g(n))$ のどれが成り立つかをすべて答えよ。

1. $f(n) = n^2,\quad g(n) = n^2 + n$
2. $f(n) = \log_2 n,\quad g(n) = \log_{10} n$
3. $f(n) = 2^{\,n},\quad g(n) = 2^{\,n/2}$
4. $f(n) = n^{\,2},\quad g(n) = 2^{\,n}$

## 予想される質問

**Q1. $O$ と $\Theta$ はどう使い分ける？**

実行時間が具体的に求まっていて「ちょうどこのオーダー」と言い切れるなら $\Theta$ を使うのが正確。$\Theta$ は上界と下界の両方を主張する強い言明だからである。一方、上界しか分からない・上界だけ保証したいときは $O$ を使う。たとえば「挿入ソートは $O(n^2)$」は正しいが、最良ケースでは $\Theta(n)$ なので「挿入ソートは $\Theta(n^2)$」と言うとケースを限定する必要がある。慣習的に、人は $O(n^2)$ と言いながら実は $\Theta(n^2)$ を意図していることも多いので、文脈に注意する。

---

**Q2. 「最悪ケース」と「上界 $O$」は同じこと？**

別の概念であり、混同しやすい。最悪・最良・平均は **どの入力を考えるか**（ケース）の話で、$O$・$\Omega$・$\Theta$ は **関数をどちら側から押さえるか**（記法）の話である。両者は独立に組み合わせられる。たとえば「挿入ソートの **最良ケース** の実行時間は $\Theta(n)$」「**最悪ケース** は $\Theta(n^2)$」「（ケースを問わず）実行時間は $O(n^2)$」のように、ケースと記法は別々に指定できる。

---

**Q3. 対数の底はなぜ気にしなくていい？**

底の異なる対数は定数倍でしか違わないから。$\log_a n = \dfrac{\log_b n}{\log_b a}$ であり、$1/\log_b a$ は $n$ によらない定数である。漸近記法は定数倍を無視するので、$\log_2 n$ も $\log_{10} n$ も同じ $\Theta(\log n)$ になる。ただし指数の底は話が別で、$2^n$ と $3^n$ は定数倍では結べない（$3^n / 2^n = (3/2)^n \to \infty$）ため、指数では底が本質的に効く。

---

**Q4. 任意の2つの関数は $O$ か $\Omega$ のどちらかで必ず比較できる？**

できない。実数なら任意の2数の大小が必ず決まる（三分律）が、漸近記法では成り立たない。$f(n) = n^{1+\sin n}$ のように指数部が振動する関数は、$g(n)=n$ に対して $O$ でも $\Omega$ でもなく、**比較不能** になる。実用上のアルゴリズム解析では行儀のよい関数ばかり扱うので問題になりにくいが、「必ず比較できる」と思い込むのは誤り。

---

**Q5. なぜ指数時間アルゴリズムは「使えない」と言い切れる？**

$n^b = o(a^n)$（$a>1$）が示すように、指数関数はどんな多項式よりいつか必ず速く増え、入力が少し増えただけで実行時間が爆発するから。第1章で見たとおり、$2^n$ は $n \approx 20$ あたりで早くも現実的な時間を超え、$n!$ はさらに急峻である。多項式時間（$P$）と指数時間の間の溝が、第1章 §1.4 の「効率的＝多項式時間」という線引きの根拠になっている。

---

**Q6. スターリングの近似はどんなときに使う？**

階乗が絡む解析で使う。階乗を直接扱うのは難しいが、$n! \approx \sqrt{2\pi n}\,(n/e)^n$ と近似すれば、桁数（対数）やオーダーを評価できる。代表的な用途は、$\lg(n!) = \Theta(n \lg n)$ を導いて **比較ソートの下界 $\Omega(n\log n)$** を証明する場面（後の章で扱う）と、第1章の巡回セールスマン問題で $(10^6)!$ の桁数を見積もる場面である。
